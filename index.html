01 / featured

AMS Scan - Platforma WMS de Depozit (PWA)

Aplicatie web PWA folosita zilnic in productie la ATV Moto Shop pentru gestionarea depozitului. 13 module (livrari, receptie, retururi, inventar, verificare produs, schimbare locatie, verificare comenzi) cu scanare de coduri prin camera telefonului (1D/2D), sincronizare in timp real intre operatori, notificari Web Push, tiparire automata de etichete pe imprimante Zebra printr-un agent Python, generare AWB pentru curieri (GLS, Sameday, Fan, DPD, UPS) si integrare cu ERP-ul RVX si PrestaShop. Peste 56 de fisiere PHP, backend MySQL, complet mobile-first, cu autentificare multi-user si permisiuni pe module.

02

Automatizare Facturi - OCR & Integrare ERP

Aplicatie desktop (Python + Tkinter) care proceseaza automat facturile PDF de la furnizori internationali (CFMOTO, ASP, MOTORIDER). Extrage produsele din PDF-uri native sau scanate folosind OCR Windows cu corectie de erori bazata pe constrangeri (~70-80% recuperare) si un fallback pe AI (Claude API) pentru facturile scanate dificile. Reconciliaza preturile din mai multe surse, calculeaza marje prin formule Excel si genereaza template-uri de import. ~4.000 linii Python, caching inteligent (TTL 24h), procesare pe fire de executie si interfata proprie cu tema dark.
