AMS Scan - Platformă WMS de Depozit (PWA)

Aplicație web PWA folosită zilnic în producție la ATV Moto Shop pentru gestionarea depozitului. 13 module (livrări, recepție, retururi, inventar, verificare produs, schimbare locație, verificare comenzi) cu scanare de coduri prin camera telefonului (1D/2D), sincronizare în timp real între operatori, notificări Web Push, tipărire automată de etichete pe imprimante Zebra printr-un agent Python, generare AWB pentru curieri (GLS, Sameday, Fan, DPD, UPS) și integrare cu ERP-ul RVX și PrestaShop. Peste 56 de fișiere PHP, backend MySQL, complet mobile-first, cu autentificare multi-user și permisiuni pe module.

PHP 8 JavaScript MySQL Python PWA REST API
Live: scan.atvmotoshop.com

Automatizare Facturi - OCR & Integrare ERP

Aplicație desktop (Python + Tkinter) care procesează automat facturile PDF de la furnizori internaționali (CFMOTO, ASP, MOTORIDER). Extrage produsele din PDF-uri native sau scanate folosind OCR Windows cu corecție de erori bazată pe constrângeri (~70-80% recuperare) și un fallback pe AI (Claude API) pentru facturile scanate dificile. Reconciliază prețurile din mai multe surse (feed-uri web + ERP RVX), calculează marje și adaosuri prin formule Excel și generează template-uri de import. ~4.000 linii Python, caching inteligent (TTL 24h), procesare pe fire de execuție și interfață proprie cu temă dark.

Python Tkinter OCR AI / Claude API pdfplumber OpenPyXL REST API
